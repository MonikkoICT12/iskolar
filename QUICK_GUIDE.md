# Quick User Guide - Fast Data Entry

## 🚀 Excel-Style Form Navigation

### How to Add Scholars Quickly (Like Excel!)

**The Old Way (Slow):** 👎
- Click field
- Type
- Click next field
- Type
- Click next field...

**The New Way (Fast!):** 👍
1. Open "Add Scholar" form
2. Start typing in First Name (auto-focused)
3. Press **Enter** → goes to next field
4. Keep typing and pressing **Enter**
5. Done! Super fast! ⚡

## 🎯 Tips for Speed

### 1. Keep Hands on Keyboard
- Don't use mouse between fields
- Type → Enter → Type → Enter

### 2. Skip Optional Fields
- Just press Enter on empty fields
- They'll be left blank (that's fine!)

### 3. Fix Mistakes Easily
- Made a typo? Press **Shift + Tab**
- Goes back to previous field
- Fix it, then press **Enter** to continue

### 4. Use Defaults
- Status defaults to "Processing" (just press Enter)
- Year Level defaults to "1st Year" (press Enter)
- Semester defaults to "1st Sem" (press Enter)

## 🐛 Troubleshooting

### Problem: Enter submits form instead of going to next field
**Solution**: This is fixed! Enter only moves between fields now.

### Problem: Can't move to next field
**Solution**: Make sure you're in an INPUT field, not a button.

### Problem: Tab goes outside form
**Solution**: Click any form field first to give form focus.

### Problem: Want to add line break in Course field
**Solution**: Course is a single-line field. Use comma for multiple courses.

## 💡 Pro Tips

### Tip 1: Speed Through Dropdowns
- Press **Tab** to enter dropdown
- Use **Arrow Keys** to select
- Press **Enter** to confirm and move

### Tip 2: Number Entry
- Don't type peso sign (₱)
- Don't use commas
- Just type: 25000 (not ₱25,000)

### Tip 3: Review Before Submit
- Last field? Don't press Enter yet
- Use **Shift + Tab** to review
- Check all fields
- Then press **Enter Enter** to submit

### Tip 4: Cancel Anytime
- Press **Escape** key
- Or click Cancel button
- Data won't be saved

### Tip 5: Muscle Memory
- After 5 scholars, you'll develop rhythm
- Type → Enter → Type → Enter
- Becomes automatic!
